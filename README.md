## Спецификаци

| № | Scenario | Хүлээгдэх HTTP статус | Хүлээгдэх `result` |
|---:|---|---:|---|
| 1 | Идэвхтэй оюутан урьдач CS201-ийг хангасан | 201 | `OK` |
| 2 | Оюутан байхгүй | 200 | `ERROR_NO_STUDENT` |
| 3 | Оюутан идэвхгүй | 200 | `ERROR_INACTIVE_STUDENT` |
| 4 | Хичээл байхгүй | 200 | `ERROR_NO_COURSE` |
| 5 | Урьдач нөхцөл CS201 дутуу | 200 | `ERROR_PREREQUISITES`, `missing` нь CS201 |
| 6 | Идэвхгүй оюутан ба байхгүй хичээлийн давхар алдаа | 200 | `ERROR_INACTIVE_STUDENT` |
| 7 | Урьдач нөхцөлгүй хичээлд хоосон coursesTaken-тэй оюутан | 201 | `OK` |
| 8 | `studentID` талбар дутуу | 400 | `ERROR_BAD_REQUEST` |
| 9 | Буруу JSON request body | 400 | `ERROR_BAD_JSON` |

## Ажиллуулах команд

Эхний терминалд:

```powershell
node server.js
```

Өөр терминалд PASS болон FAIL collection-уудыг Newman-аар ажиллуулна. Серверийг
унтраасны дараа үндсэн collection-ийг дахин ажиллуулж DOWN (`ECONNREFUSED`) нотолгоог авна.
Бодит гаралтууд, assertion тоо, exit code болон дүгнэлтийг ажиллуулалтын дараа энэ README-д
тэмдэглэнэ.
